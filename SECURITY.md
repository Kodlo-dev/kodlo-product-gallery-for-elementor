# Security Policy

## Supported versions

Security fixes are provided for the latest stable release of Kodlo Product Gallery for Elementor.

| Version | Supported |
| --- | --- |
| 2.9.6 | Yes |
| Earlier releases | No; update to the latest stable release first |

## Reporting a vulnerability

**Security Contact:** [https://kodlo.dev/](https://kodlo.dev/)

Report suspected vulnerabilities privately through the **Contact** button at that address. Start the message with `Security report: Kodlo Product Gallery for Elementor` so it can be triaged correctly.

Include:

- the affected plugin, WordPress, PHP, WooCommerce, Elementor, and browser versions;
- the required user role or capabilities;
- reproducible steps and a minimal proof of concept;
- the observed and potential impact;
- relevant logs or screenshots with sensitive values removed.

Do not include passwords, API keys, access tokens, customer data, or other personal data. Do not publish exploit details in a support topic or public issue before coordinated disclosure.

## What to expect

- An initial response is normally sent within five business days.
- The report will be reproduced, assessed, and prioritized according to its impact and exploitability.
- Material status changes will be shared with the reporter when possible.
- Disclosure timing will be coordinated after affected users have had a reasonable opportunity to install a fix.

Kodlo does not currently operate a vulnerability bounty program.

## Scope and supported runtime

This policy covers code shipped with Kodlo Product Gallery for Elementor. Elementor, WooCommerce, WordPress, video providers, media upload handlers, and other plugins remain under their respective security policies. Report vulnerabilities in those components to their maintainers.

PHP 8.2 or newer is recommended for production because it remains supported by the PHP project. PHP 8.1 is retained as the minimum runtime compatibility requirement for Kodlo Product Gallery for Elementor 2.9.6; this minimum does not imply that unsupported PHP branches are recommended for production use.
