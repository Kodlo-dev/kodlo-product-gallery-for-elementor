# Kodlo Product Gallery for Elementor

Use one Elementor widget to design a desktop image grid and a touch-friendly mobile slider. Choose the breakpoint, control each layout independently, and give product variations their own images without building separate galleries.

[WordPress.org listing and Live Preview](https://wordpress.org/plugins/kodlo-product-gallery-for-elementor/) · [Kodlo](https://kodlo.dev/)

## Responsive product media in one Elementor widget

- **Design your desktop grid.** Choose columns, gaps, image limits, and aspect ratios. Stretch an unmatched first or last image to fill the row when the layout calls for it.
- **Tune the mobile gallery.** Add swipe navigation, thumbnails, arrows, pagination, and optional edge bleed. Use any enabled Elementor breakpoint for the layout switch.
- **Show the right variation images.** Assign media in WooCommerce Product data. The gallery can respond to a meaningful partial selection, such as color, and avoids rebuilding when the effective media is unchanged.
- **Include video with your images.** Assign a YouTube, Vimeo, or MP4 URL to an image attachment. The image stays available as the poster and thumbnail.
- **Style media and playback in Elementor.** Set separate zoom or magnifier controls for desktop and mobile. Style navigation, thumbnails, captions, and sale badges with familiar Elementor controls.
- **Manage loading priorities.** The optional image loading controls set priority counts and defer off-screen media. WordPress attachment sizes and responsive image attributes remain in use.

## Requirements

WordPress 6.6 or later, PHP 8.1 or later, WooCommerce 9.0 or later, and Elementor 3.22 or later.

## Installation

1. Activate WooCommerce, Elementor, and Kodlo Product Gallery for Elementor.
2. Open a WooCommerce product page in Elementor or a Single Product template. Add the **Kodlo Product Gallery** widget in a product context.
3. Set the grid, slider, breakpoint, and image behavior. Add variation images in the WooCommerce product editor if needed.
4. Preview a product at multiple viewport sizes and switch between its variations before publishing the layout.

## Frequently asked questions

### Do I need Elementor Pro?

The widget can run with Elementor Free. Elementor Pro is required for Pro features such as building Single Product templates with Theme Builder.

### Can I try the gallery with a variable product?

The WordPress.org listing offers **Live Preview** in a temporary WordPress Playground with a prepared variable product and gallery.

### Can I move existing WooGallery media settings?

A guided migration can copy supported WooGallery metadata after an authorized administrator confirms it. Legacy cleanup is a separate optional action.

## Privacy and external services

Gallery settings and media assignments stay in WordPress. When a visitor starts a video, the browser loads the selected YouTube or Vimeo player or requests the configured MP4 host.
